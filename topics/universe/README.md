# 題目宇宙:台科大資工系六個研究群的候選題目(總覽)

查證日期 2026-11-23。這份總覽把六份分群報告的 18 個候選放在一張表上,讓你先刪再選。每個候選的細節、引文與來源在各自的報告裡。

## 這份報告怎麼做的
1. **領域以系上為準。** 從系網「專任/專案師資」頁抄錄 32 位教師的專長,並抓了 28 位教師的個人或實驗室網站(含研究與著作子頁)。見 [ntust-csie-faculty.md](ntust-csie-faculty.md)。
2. **依教師專長分成六群**(分群是 agent 做的,不是系上的官方分組),每群由一個獨立的查證工作負責:先讀該群教授的網站,再找貼近某位教授實際研究的題目。
3. **每個候選都做三項缺口檢查**:引用定義論文的最新論文(OpenAlex)、2025 年起已發表的論文(OpenAlex)、arXiv 最新預印本;並開啟 1 到 2 篇定義論文的全文,引用一句說明未解問題的原文。
4. **假設學習成本不計**(你的指示),所以判準 1「跟得上」這次沒有評。

## 跨報告的發現
- **你保留的 `kv-offload-aging-flash` 在系上有直接的人可問。** [quote-verified: 謝仁偉實驗室網站著作清單] 謝仁偉教授有 "Read Retry Mechanism for 3D NAND Flash Memory: Observations, Analyses, and Solutions"(2024)與 "Adaptive Read Retry Table Extension for Enhanced Data Reliability in 3D ..."(DAC 2026)。前一篇是在真實平台上量 3D TLC 的 read retry,這正是你認為最大的問題(拿不到可計重試的平台)該去問的地方。
- **`kv-zns-write-amp` 出現直接競爭者。** [source-exists, 只看索引] "LifeKV"(IISWC 2026, doi:10.1109/iiswc71020.2026.00028)。評估那個候選時要先讀它。
- **專長標籤與實際在做的事不一定一致。** 鍾國亮列的是視訊壓縮,但 2023 年起 OpenAlex 上的 8 篇是點雲配準與特徵匹配。馮輝文、戴碧如、陳怡伶網站上最新的著作分別停在 2006、2016、2017。鄧惟中的網站寫他 2025 年 8 月起借調到電信技術中心。找指導教授時以近年著作為準。
- **純機制設計理論(原本的 `tfm`)在系上沒有相鄰教授。** 所以區塊鏈那一群改提「手續費機制加排隊或網路效能模型」這種接得上周詩梵與馮輝文專長的題目。
- **排隊與效能建模是你可以跨群重用的工具。** predicted-dispatch-fog、eip1559-wait-queue、purify-buffer-policy 和既有的 5g-core-metastability、qkd-keypool-backpressure 都用它。

## 這份報告的限制
- **arXiv API 整段時間都被限流**(回 429)。六份報告都改用 arXiv 的網頁搜尋或 OpenAlex 補,所以「最新預印本」這一步的涵蓋率比正常低。各報告都標明了哪些查詢沒有成功。
- **引用清單大多只看了最新 12 到 25 筆的標題。**
- **付費牆後的論文只看到摘要或索引**(ACM DL 回 403、TIFS、TDSC)。有幾篇正好是決定缺口是否存在的論文,表中「還缺什麼」已列出。
- **分群報告由六個獨立的查證工作撰寫**,我核對了它們回報的摘要、各檔的等級標記數,以及謝仁偉網站上那兩篇 read retry 論文;沒有逐句重查每一份的引文。
- **賴祐吉、項天瑞的網站沒有載入;林佳志沒有網站連結。** 這三位的相鄰性只依據系網的專長欄。
- **Consensus、Google Scholar、DBLP、Semantic Scholar 都沒有用到。**
- 「夠不夠新」與「夠不夠成為一篇論文」是估計,最後要問教授。
